# LGM7 目录发行手工验收

最后更新：2026-09-09

本文只覆盖目录候选的客户可见启动和关闭，不要求登录 Provider、不执行联网、导入客户材料或准备 OCR/向量模型。
自动化回归已覆盖目录结构、随包后端、可选组件缺失、损坏 MCP 状态、进程清理和固定长任务取消；本清单补足 Qt 窗口本身的人工观察。

## 准备

1. 确认没有正在运行的 AgentFlow；若端口 `8765` 已被其它实例占用，先关闭那个实例。
2. 打开目录候选根目录中的 `AgentFlow.exe`，不要从 `backend/` 单独启动后端。
3. 整个过程保持默认离线状态：不配置模型 Key、不启用 MCP、不点击安装 OCR 或语义模型。

## 验收步骤

1. 双击 `AgentFlow.exe` 后，确认主窗口可在合理时间内出现，左侧导航、AI 调度台和基础页面可点击；不应出现“找不到后端”或无限加载。
2. 依次进入 AI 调度台、文档助手、数据工作台和知识库，再回到 AI 调度台。确认页面切换没有卡死；知识库中的 OCR/语义索引若未准备，应显示明确的可选状态，而不是自动下载或阻塞启动。
3. 在 AI 调度台输入一句普通离线问题，例如“解释什么是检索增强生成”，确认输入可以提交并显示明确的本地/mock 状态；此项不验证模型答案质量，也不应触发真实 Provider。
4. 关闭主窗口。等待约 10 秒后，确认窗口消失；再次打开候选包应能正常启动。若观察任务管理器，前一次的 `AgentFlow.exe` 与 `AgentFlowBackend.exe` 不应继续驻留。

## 通过与失败

- 通过：启动、四个页面切换、输入反馈和关闭重启均正常；未出现隐式 Node/MCP/OCR 下载或客户数据目录写入。
- 失败：记录界面提示、操作步骤、是否能重现和大致时间；不要粘贴 API Key、资料正文、完整日志或用户目录绝对路径。若是端口占用、后端缺失或可选组件未准备，按界面提示恢复后再复测。

## 不在本轮验收内

- 真实模型回答质量、真实公网/MCP 可用性、认证、限流与供应商计费。
- OCR 模型下载、扫描件识别、向量模型准备和客户资料索引。
- 代码签名、安装器、自动升级和正式对外发布。
